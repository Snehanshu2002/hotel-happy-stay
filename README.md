# HOTEL HAPPY STAY – Premium Restaurant & Hospitality Website

Official website for **HOTEL HAPPY STAY**, located in Tangi, Chandrapur, Odisha, India along National Highway 16 (NH 16).

---

## 🌟 Overview

HOTEL HAPPY STAY is a highway dining destination and stopover along the Berhampur–Bhubaneswar NH 16 corridor in Odisha. This website establishes the hotel's digital presence, introducing the restaurant to highway travelers, families, and local patrons.

- **Google Rating**: 4.6 / 5.0 (over 2,160+ verified reviews)
- **Cuisine**: Authentic Coastal Odia Seafood, Indian Main Course, Tandoori Specialties, and Chinese Cuisines
- **Facilities**: Air-conditioned family dining hall, spacious vehicle parking, and highway lodging

---

## 🚀 Features

- **Genuine Hotel Photography**: Verified photographs of the 3-storey building facade, glass entrance, reception, AC dining hall, and food.
- **Interactive Menu**: 8 categories (Seafood, Chicken, Fish & Prawn, Vegetarian, Main Course, Chinese, Tandoor & Starters, Rice & Breads) with search and Veg/Non-Veg filters.
- **Signature Specialties**: Showcase of Crab Masala, Tandoori Pomfret, Tiger Prawn Chilli, Butter Naan, Chicken Pakoda, Chilli Chicken, Fish Finger, and Seafood Platter.
- **Visual Gallery with Lightbox**: Filterable by Exterior, Interior, Dining Area, Seafood, Indian Dishes, and Ambience.
- **Highway Route Guide & Transit Info**: Click-to-call, WhatsApp inquiry, interactive Google Map, and distance guide (Bhubaneswar ~70 km, Berhampur ~100 km, Chilika ~25 km).
- **Mobile First Experience**: Sticky navigation, mobile slide-out drawer, and bottom quick-action bar for road commuters.
- **SEO & Schema**: Schema.org JSON-LD structured data for `Restaurant` and `LocalBusiness`.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS (Custom luxury charcoal, gold, and cream palette)
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Hosting**: Netlify Free Plan (100% free hosting with global CDN)

---

## 💻 Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```

---

## 🌐 Netlify Deployment

Configured with `netlify.toml` and `public/_redirects`:
- **Build command**: `npm run build`
- **Publish directory**: `dist`
- **Routing**: Single Page Application (SPA) redirects to `/index.html` with HTTP 200
